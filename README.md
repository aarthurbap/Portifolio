# Portfólio | Arthur Baptista

Portfólio pessoal desenvolvido com **HTML5, CSS3 e JavaScript**, criado para apresentar minha trajetória na tecnologia, meus conhecimentos, projetos e formas de contato.

O site possui um design **moderno, responsivo e minimalista**, com fundo preto profundo e detalhes em roxo neon suave.

## Sobre mim

Sou estudante do curso Técnico em **Análise e Desenvolvimento de Sistemas (ADS)** na **Firjan-SENAI** e desenvolvedor Full Stack em formação.

Estou em busca de uma oportunidade na área de **Tecnologia da Informação**, onde possa aplicar meus conhecimentos, adquirir experiência profissional e continuar evoluindo como desenvolvedor.

Tenho interesse em desenvolvimento de software, APIs, bancos de dados e automação de processos, buscando criar soluções funcionais para problemas reais.

## Funcionalidades

- **Página inicial:** apresentação profissional e acesso rápido aos projetos e contatos.
- **Sobre mim:** informações sobre minha formação, interesses e objetivos profissionais.
- **Habilidades:** tecnologias que estudo e utilizo.
- **Projetos:** cards com descrições, tecnologias e links para o GitHub.
- **Contato:** acesso ao e-mail, LinkedIn, GitHub e Instagram.
- **Design responsivo:** adaptação para computadores, tablets e celulares.
- **Navegação:** menu adaptável a dispositivos móveis e rolagem suave entre as seções.

## Estrutura do projeto

```text
Portifolio/
├── index.html
├── estilo.css
├── script.js
└── README.md
```

**Atenção:** o nome do arquivo CSS deve corresponder ao nome usado no `href` da tag `<link>` dentro do `index.html`. Neste repositório, o arquivo aparece como `estilo.css`.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/aarthurbap/Portifolio.git
   ```

2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo `index.html` no navegador. Se preferir, utilize a extensão **Live Server** do VS Code.

Não é necessário instalar bibliotecas, frameworks ou banco de dados para executar o portfólio.

## Publicação no GitHub Pages

1. Entre no repositório no GitHub.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação do endereço do site no GitHub Pages.
